# API Reference

Base URL: `http://localhost:8000` (local) or your Render service URL.
Interactive docs (Swagger UI) are auto-generated by FastAPI at `/docs`.

| Method | Path                              | Purpose                                   |
|--------|-----------------------------------|--------------------------------------------|
| GET    | `/api/health`                     | Liveness/readiness check                  |
| GET    | `/api/datasets`                   | List all registered datasets              |
| GET    | `/api/datasets/{id}`              | Get one dataset's full metadata           |
| POST   | `/api/aoi/validate`               | Validate an area of interest              |
| POST   | `/api/extractions`                | Start an extraction job                   |
| GET    | `/api/extractions/{job_id}`       | Poll job status/progress                  |
| GET    | `/api/extractions/{job_id}/download` | Download the completed study-area ZIP  |
| POST   | `/api/preview`                    | AOI + dataset coverage + size estimate    |
| POST   | `/api/convert`                    | Standalone format conversion (file upload)|
| GET    | `/api/files/{key}`                | Serves local-storage-backed files         |

## `POST /api/aoi/validate`

```json
{ "aoi_type": "bbox", "bbox": { "north": 8.2, "south": 7.7, "east": 4.1, "west": 3.6 } }
```
Other `aoi_type` values: `polygon` / `geojson` (send `geojson: <Feature|FeatureCollection|Geometry>`),
`circle` (send `circle: {center_lat, center_lon, radius_km}`), `rectangle` (alias of `bbox`).

Response:
```json
{
  "valid": true,
  "area_km2": 3048.48,
  "bbox": { "north": 8.2, "south": 7.7, "east": 4.1, "west": 3.6 },
  "geojson": { "type": "Polygon", "coordinates": [[]] },
  "errors": [],
  "warnings": []
}
```

## `POST /api/extractions`

```json
{
  "aoi": { "aoi_type": "bbox", "bbox": { "north": 8.2, "south": 7.7, "east": 4.1, "west": 3.6 } },
  "datasets": [
    { "dataset_id": "global_dem" },
    { "dataset_id": "geology", "output_format": "Shapefile" },
    { "dataset_id": "mineral_occurrences", "output_format": "CSV" }
  ],
  "processing": {
    "mode": "advanced",
    "clip": true,
    "reproject_to": "EPSG:32631",
    "resample": "bilinear",
    "simplify_tolerance": 0.001,
    "dissolve": false,
    "buffer_meters": null,
    "attribute_filter": null
  },
  "study_area_name": "oyo_study_area"
}
```
Response: `{ "job_id": "...", "status": "queued" }`

## `GET /api/extractions/{job_id}`

```json
{
  "job_id": "...",
  "status": "processing",
  "stage": "extracting",
  "progress_pct": 35,
  "message": "Extracting Geological Units (2/3)",
  "created_at": "...",
  "updated_at": "...",
  "result_files": [],
  "download_url": null,
  "error": null
}
```
`status`: `queued | processing | completed | failed`.
`stage`: `preparing | extracting | converting | packaging | complete | failed`.

## `POST /api/convert`

`multipart/form-data`: `file`, `kind` (`raster`|`vector`), `output_format`.
Response: `{ "download_url": "..." }`.
